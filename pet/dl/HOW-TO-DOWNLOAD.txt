企鹅桌宠 · 国内网络下载说明（不依赖 GitHub 下载服务器）
=====================================================

为什么有这个页面？
  GitHub 的文件下载服务器（objects.githubusercontent.com）在国内经常被阻断，
  点下载会出现"没反应 / 失败 / 一直转圈"。而本站（github.io）可以正常访问，
  所以这里放了一份分片镜像，下载更稳。

桌面版怎么下载（4 步，约 2 分钟）
  1) 把下面 4 个分片全部下载下来（缺一个都合并不了）：
        PenguinPet-Windows-x64.zip.001
        PenguinPet-Windows-x64.zip.002
        PenguinPet-Windows-x64.zip.003
        PenguinPet-Windows-x64.zip.004
  2) 再下载合并脚本：
        merge-and-unzip.bat
  3) 把这 5 个文件放进同一个文件夹
  4) 双击 merge-and-unzip.bat → 自动合并出 PenguinPet-Windows-x64.zip
     → 右键解压 → 双击里面的 PenguinPet.exe，完成！

  提示：
   · 合并用的是 Windows 自带命令，不需要安装任何软件
   · 如果浏览器把 .bat 保存成了 .bat.txt，改回 .bat 即可
   · 分片与官方 zip 完全一致（已做 SHA256 校验）

只想先尝尝鲜？
  下载 PenguinPet-Lite.zip（约 16KB），解压后双击 start.bat，
  用系统自带浏览器开个小窗口就能玩（缺点：企鹅不会悬浮在其他窗口之上）。
